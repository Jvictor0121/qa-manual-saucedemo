# 🧪 Testes Manuais - SauceDemo

Repositório dedicado à prática e documentação de testes manuais de software (QA), utilizando a aplicação web de e-commerce **SauceDemo** (`https://www.saucedemo.com`).

## 🎯 Objetivo
Demonstrar habilidades práticas na elaboração de planos de teste, escrita de cenários no formato BDD (Behavior-Driven Development) e reporte estruturado de defeitos (Bug Reports).

## 📋 Escopo Testado
* **Autenticação:** Login com credenciais válidas, inválidas, campos vazios e usuários com restrições.
* **Carrinho de Compras:** Adição, remoção e persistência de itens.
* **Checkout:** Preenchimento de dados e finalização de pedido.

## 📂 Arquivos do Projeto
* [`casos-de-teste.md`](./casos-de-teste.md) - Cenários de teste positivos e negativos escritos em Gherkin (Dado/Quando/Então).
* [`bug-reports.md`](./bug-reports.md) - Registro de defeitos reais encontrados durante os testes exploratórios.
